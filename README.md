# Hermes Voice Chat UI

This repository hosts a minimal web UI that lets you talk to Hermes via voice.

* Uses the built‑in `/voice-chat` endpoint on the Hermes server.
* Includes a Telegram login widget for authentication (placeholder auth URL).
* Adds a small explanatory text section as requested.

## Deploy

Enable GitHub Pages (branch `main`, root) and point your DigitalPlat free domain (e.g. `brisk-voice.digitalplat.org`) to the Pages site.
